# chat-code 记忆管理规划

> 目标:把 Claude Code 那套"看不见的文件式记忆"变成 chat-code 里**可视、可审、可搬**的资产。
> 分三层推进:看得见 → 管得动 → 搬得走。本文件是总规划,逐层实现,勾掉已完成项。

## 背景机制(约束)

- 记忆存储:`~/.claude/projects/<项目路径编码>/memory/` 下,一条事实一个 `*.md` + 一个 `MEMORY.md` 索引。
  - 路径编码规则:把项目绝对路径里的 `/` 和 `.` 都换成 `-`(如 `/Users/tou/MyProject/chat-code` → `-Users-tou-MyProject-chat-code`)。
  - 记忆文件 frontmatter:`name` / `description` / `metadata.type`(user|feedback|project|reference)/ `metadata.originSessionId`。
  - `MEMORY.md` 每条一行 `- [标题](file.md) — 钩子`。
- 三个动作:
  - **存/更新** = agent 用 Write/Edit 写 `memory/*.md`(并需同步 MEMORY.md)。
  - **引用/回忆** = agent 用 Read 打开某条 `memory/*.md`(排除 MEMORY.md 索引本身)。
- 已知痛点:**索引漂移**——文件写了但没登记进 MEMORY.md(实测普遍存在);相对日期未转绝对;重复记忆。
- 跨端根因:存储目录名含**本机绝对路径**,换机/换路径即失联。跨电脑必须先解决寻址方式。
